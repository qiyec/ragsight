## 一句话说清这个项目

**ragsight 是一个诊断工具：帮人看清 RAG 到底哪一步不行。**

它不实现检索框架本身（那是 AgentScope 官方在做的事），
它做的是把检索拆成能单独量的几步，分别给指标，指出瓶颈在哪。

这个定位决定了架构：**它必须是一把可信的尺子**，
所以结论必须可复现、算法必须能独立验证。下面所有设计都是为这个服务的。
