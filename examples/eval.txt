# 示例评测集
#
# 用法：
#   java -jar ragsight-cli/target/ragsight-cli.jar diagnose \
#        --corpus examples/corpus --eval examples/eval.txt
#
# 格式说明见 examples/eval-format.txt
#
# 这里刻意放了两类不同难度的问题：
#   - 精确编号类（错误码）：向量召回容易漏，关键词召回更有优势
#   - 同义改写类：问题用词和文档不完全一致，考验语义匹配
# 两类混在一起，诊断报告才有区分度。如果全是"和文档用词一样"的问题，
# 各种召回方式的表现会一模一样，报告也就给不出任何建议。

# ---- 精确编号类 ----

Q: 错误码 E4021 是什么意思
E: E4021 表示计费账户被冻结

Q: E1002 错误怎么处理
E: E1002 表示账号已被锁定

Q: 错误码 E4023 代表什么
E: E4023 表示计费项配置冲突

---

# ---- 同义改写类 ----

Q: 账单什么时候出
E: 次月 3 日前生成

Q: 密码输错太多次会怎样
E: 锁定账号 30 分钟

Q: 存储快满的时候有提醒吗
E: 达到配额的

Q: 出站流量怎么收费
E: 出站流量计费

Q: 单点登录怎么配
E: 配置身份提供方信息
