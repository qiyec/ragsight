# 评测集文件格式说明
#
# 用法： ragsight diagnose --corpus <文档目录> --eval <本文件>
#
# 一个用例一个块，块之间用空行或 --- 分隔。
#
#   Q: 用户问题（必填）
#   E: 期望被召回的片段里应当出现的一段文字（必填，可以写多条）
#   E: 再来一条
#
# 说明：
#
# 1. E 写的是"关键文字"而不是片段编号。
#    片段编号形如 billing.md#3，那个 3 取决于切分参数。一旦调整切分，
#    写死的编号就会指向不存在的片段，指标会全变成 0，而你多半会
#    以为是检索坏了。写关键文字就不会有这个问题——切分怎么变都能找到。
#
# 2. 只写能唯一确定片段的那一小段就够，不用抄一整句。
#    原因：文件里的换行和空格很容易和你写的对不上（尤其是 Markdown
#    的多行段落），写得越长越容易对不上。
#
# 3. 如果某个用例**故意**找不到期望文字，会直接报错而不是静默跳过。
#    这是刻意的：静默跳过会让评测集悄悄失效，比直接报错危险得多。
#
# 4. 想测"这个问题本来就该答不出来"（负样本），就只写 Q 不写 E。
#    负样本很重要：没有它，一个"永远返回最相似内容"的检索器也能拿高分。
#
# ============================================================
# 下面是一个可用的例子（可以删掉换成你自己的）
# ============================================================

Q: 账单什么时候生成
E: 账单会在次月 3 日前生成

Q: 存储满了会怎样
E: 达到配额的
E: 90%时

Q: 出站流量怎么计费
E: 网络流量按出站流量计费

---

Q: 密码输错多次会锁定吗
E: 连续输错密码 5 次会锁定账号

Q: 错误码 E4021 是什么
E: E4021 表示计费账户被冻结
